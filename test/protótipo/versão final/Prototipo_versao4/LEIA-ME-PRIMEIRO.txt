DIREITOS E DEVERDADE — HTML, CSS E JAVASCRIPT PURO
================================================

COMO ABRIR

1. Extraia o ZIP inteiro (não abra o HTML ainda dentro do ZIP).
2. Abra a pasta extraída.
3. Dê dois cliques no arquivo index.html.
4. O navegador abrirá a HOME com os cinco cards.

NÃO execute npm install ou npm run dev nesta versão.
NÃO precisa de Node, React, Vite, Tailwind ou extensão do VS Code.
NÃO copie esta pasta por cima da versão React; mantenha as duas separadas.

O endereço no navegador pode começar com file:///C:/... . Isso é normal.

PARA EDITAR

Abra a pasta extraída no VS Code. Edite um arquivo, salve com Ctrl+S
 e atualize a aba do navegador. A página inicial está em index.html;
 os conteúdos estão nos HTMLs da pasta pages.

Não mova só o index.html: ele precisa continuar ao lado de css, js,
assets e pages. Todos os caminhos dos recursos são relativos.

Os links de fontes oficiais precisam de Internet, mas são opcionais.
Nenhum recurso externo é necessário para carregar o conteúdo do site.
As respostas dos exercícios não são enviadas nem salvas permanentemente.

Veja README.md para a estrutura e docs/COMO-ENTENDER-O-CODIGO.md para
começar a estudar HTML, CSS, JavaScript e DOM usando estes arquivos.

Testes e limites do ambiente estão em docs/TESTES.md.
